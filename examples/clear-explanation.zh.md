把各产品的销售额画成柱状图，可以直接比较谁卖得多。正文先讲清用途，补充用法再展开。

## A 正文讲清用途，也保留限制
新版能把数字表画成图。比如给一张各产品销售额表，就能生成柱状图，一眼看出谁卖得多。

它能比较已有数字。要看改价格后销量会怎样，还需要另外建立计算模型。

```html
<details>
<summary>支持哪些图，怎么提供数字？</summary>
<p>比较产品销售额时用柱状图；看每月变化时用折线图；看各类占比时用饼图。</p>
<p>在草稿中写明图表类型，再提供名称与数字，工具负责绘制。</p>
</details>
```

## B 关系复杂时，用图讲过程
例如介绍一个客服 Agent，可以把是否检索、查不到时如何处理画出来：

```flow
收到问题 -> {资料够用吗?}: 判断
{资料够用吗?} -> 直接回答: 够用
{资料够用吗?} -> 检索资料: 不够
检索资料 -> 根据结果回答: 找到答案
检索资料 -> 追问或转人工: 没找到
```
